# Audit of Paid and Licensed Tools, Libraries, and Infrastructure in CI/CD Pipelines

## Executive Summary & Cost Analysis Framework

This document audits all **paid, commercial, licensed, proprietary SaaS, and external infrastructure tools** used in this repository's 45 CI/CD pipelines.

### Understanding the Cost Columns

Per project requirements, the cost analysis is presented across two clear operational states:
1. **Original Rough Cost (Before Your Changes)**: The actual operational and subscription cost required to run the original upstream workflow as originally configured (e.g., upstream foundation multi-cloud hosting, proprietary self-hosted runners, paid SaaS tiers, commercial compute rates, or dedicated bot seats).
2. **Current Cost in Your Modernized Fork (After Your Changes / Right Now)**: **\$0.00 (Zero)** across the board, achieved through our **Dual-Mode Architecture** and GitHub-native alternatives running on a public repository.

## Detailed Tool Breakdown (Before vs. After Your Changes)

### 1. Node.js Foundation Custom Self-Hosted Runners (`ubuntu-slim`)
* **Before Your Changes**: The upstream Node.js repository hardcoded `runs-on: ubuntu-slim` in 42 workflows. Running this as-is requires provisioning and managing dedicated cloud virtual machines (or Kubernetes runner pods) with pre-baked toolchains, costing **\$500 – \$2,500/month** in dedicated server infrastructure.
* **After Your Changes**: Configured with dynamic runner expressions (`runs-on: ${{ vars.RUNNER_LABEL || 'ubuntu-latest' }}`). Runs on standard GitHub-hosted `ubuntu-latest` at **\$0.00**.

### 2. OpenJS Foundation Jenkins Build Farm (`ci.nodejs.org`)
* **Before Your Changes**: `auto-start-ci.yml` and `commit-queue.yml` called `ci.nodejs.org` using private tokens (`JENKINS_USER`, `JENKINS_TOKEN`). Upstream operates a massive build farm of 100+ physical and virtual servers across Equinix Metal, AWS, DigitalOcean, and Rackspace costing **\$3,000 – \$10,000+/month**.
* **After Your Changes**: Refactored to execute locally on GitHub Actions runners with a simulation fallback that outputs markdown execution reports. Cost in your fork: **\$0.00**.

### 3. GitHub-Hosted Managed ARM64 Runners (`ubuntu-24.04-arm`)
* **Before Your Changes**: `build-tarball.yml`, `coverage-linux.yml`, and `test-shared.yml` hardcoded `runs-on: ubuntu-24.04-arm`. GitHub bills ARM64 runners at **\$0.005/min** (2-core) or **\$0.010/min** (4-core) against the Enterprise account even in public repositories. High-frequency CI runs would cost **\$500 – \$1,500/month**.
* **After Your Changes**: Configured with fallback expressions (`runs-on: ${{ vars.ARM_RUNNER_LABEL || vars.RUNNER_LABEL || 'ubuntu-latest' }}`). Defaults to free standard `ubuntu-latest`, reducing cost to **\$0.00**.

### 4. Cachix Nix Binary Cache
* **Before Your Changes**: Workflows pushed to `https://nodejs.cachix.org` using `CACHIX_AUTH_TOKEN`. Caching multi-GB Node.js build artifacts on Cachix requires a Pro or Team plan costing **\$40 – \$200/month**.
* **After Your Changes**: Workflows detect if `CACHIX_AUTH_TOKEN` is present. If absent, Cachix push is skipped, and builds use standard Clang/GCC compilers or GitHub's free 10 GB Actions Cache. Cost: **\$0.00**.

### 5. Slack Messaging (`action-slack-notify`)
* **Before Your Changes**: `notify-on-push.yml`, `notify-on-review-wanted.yml`, and `post-release.yml` required `SLACK_WEBHOOK`. Commercial Slack subscriptions cost **\$7.25 – \$12.50/user/month** (Pro/Business+) or **\$15–\$25/user/month** (Enterprise Grid).
* **After Your Changes**: If `SLACK_WEBHOOK` is missing, notifications render directly into `$GITHUB_STEP_SUMMARY`. Cost: **\$0.00**.

### 6. Upstream Bot User Accounts (`GH_USER_TOKEN`)
* **Before Your Changes**: 22 workflows required `GH_USER_TOKEN` (a personal access token for a dedicated bot user account, e.g., `nodejs-github-bot`). In GitHub Enterprise, allocating an enterprise seat for an automation bot costs **\$21/user/month**.
* **After Your Changes**: All workflows execute using the built-in, free repository `${{ secrets.GITHUB_TOKEN }}` with explicit permissions. Cost: **\$0.00**.

### 7. Mozilla sccache Cloud Storage
* **Before Your Changes**: Workflows configured sccache with cloud object storage backends (AWS S3, Google Cloud Storage), incurring **\$10 – \$50/month** in storage and egress fees.
* **After Your Changes**: Integrated with native GitHub Actions Cache (`actions/cache@v4`), which provides 10 GB of free cache storage per repository. Cost: **\$0.00**.
